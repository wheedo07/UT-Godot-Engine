## Introduction

**UT-Godot-Engine** is an **Undertale-style fan game development framework (GDExtension)** for Godot Engine 4.5+.
It provides the systems and tools needed to quickly build battle, dialogue, and overworld flows.

> This engine is written in C++ (GDExtension), offering both high performance and flexibility.

### This documentation
- Helps you quickly understand the framework overview and core features
- Serves as the entry point to the documentation and tutorials.

---

## Key Features

- **Turn-based battle system**: Implements Undertale-style battle mechanics
- **Dialogue tools**: Text box, typing effect, and animation support
- **Overworld system**: Map navigation, NPC interaction, and event trigger functionality
- **Save/Load**: Save and load game progress
- **Modular design**: Each system can be used independently
- **Platform support**: Windows and Android supported

## Getting Started
### 📥 Opening the Project
1. [Download the latest release](https://github.com/wheedo07/UT-Godot-Engine/releases)
2. Extract the archive and check the folder name
3. Launch Godot Engine 4.5+
4. Click `Import` → Select the `project.godot` file
5. Open the project
