# OverworldSprite

> 🟢 **사용자 생성 가능**
>> 사용자가 노드를 생성하고 스크립트를 작성할 수 있습니다.

---

## 주요 역할
- 자동 애니메이션 설정
    - 캐릭터 이동에 필요한 표준 애니메이션 세트를 자동 생성
    - 에디터에서 사용 시 기본 애니메이션 구조 자동 구성
- 알림 시스템
    - [`alert_offset`](#alert_offset-vector2) 속성을 통한 알림 위치 세밀 조정
- [`OverworldCharacterNode`](OverworldCharacterNode.md)와의 통합
    - 캐릭터 노드의 자식으로 사용되어 애니메이션 모습 처리

---

## 자동 애니메이션 설정

에디터에서 사용할 때 다음 애니메이션들이 자동으로 생성됩니다:

| 애니메이션 이름 | 설명 | 사용 시기 |
|----------------|------|-----------|
| `"act"` | 특수 액션 애니메이션 | 특별한 상호작용 시 |
| `"idle_down"` | 아래 방향 대기 애니메이션 | 아래쪽을 바라보며 정지 |
| `"idle_side"` | 옆 방향 대기 애니메이션 | 좌우를 바라보며 정지 |
| `"idle_up"` | 위 방향 대기 애니메이션 | 위쪽을 바라보며 정지 |
| `"move_down"` | 아래 방향 이동 애니메이션 | 아래쪽으로 이동 |
| `"move_side"` | 옆 방향 이동 애니메이션 | 좌우로 이동 |
| `"move_up"` | 위 방향 이동 애니메이션 | 위쪽으로 이동 |

```gdscript
# 애니메이션은 자동으로 생성되므로 별도 설정 불필요
# 캐릭터 노드가 자동으로 상태에 따라 적절한 애니메이션 재생
```

---

## 멤버 변수

### 에디터에서 설정 가능한 변수

#### `alert_offset: Vector2`
스프라이트를 기준으로 한 알림 표시기의 오프셋 위치입니다.
캐릭터가 조우나 상호작용을 유발할 때 나타나는 알림 기호(느낌표 등)가 표시될 위치를 결정합니다.
